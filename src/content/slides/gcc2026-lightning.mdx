<h2 style="font-size: 1.28em;">Make "I don't know yet" first-class</h2>

<div style="display: grid; grid-template-columns: minmax(0, 0.98fr) minmax(0, 1.02fr); gap: 0.8em; align-items: stretch; margin-top: 0.65em;">
  <div style="text-align: left;">
    <div style="border-left: 6px solid #d0bd2a; padding-left: 0.65em; margin-bottom: 0.75em;">
      <div style="font-size: 0.48em; font-weight: 900;">Concrete now</div>
      <div style="font-size: 0.36em; line-height: 1.32; opacity: 0.78;">inputs, outputs, step set, producer → consumer edges, branches, `when:` guards</div>
    </div>
    <div style="border-left: 6px solid #d0bd2a; padding-left: 0.65em; margin-bottom: 0.75em;">
      <div style="font-size: 0.48em; font-weight: 900;">Deferred explicitly</div>
      <div style="font-size: 0.36em; line-height: 1.32; opacity: 0.78;">`TODO_*` sentinels for tool IDs, versions, and wrapper-defined ports</div>
    </div>
    <div style="border-left: 6px solid #25537b; padding-left: 0.65em;">
      <div style="font-size: 0.48em; font-weight: 900;">Intent carried forward</div>
      <div style="font-size: 0.36em; line-height: 1.32; opacity: 0.78;">`_plan_*` fields tell the next step what the source evidence supports.</div>
    </div>
  </div>
  <pre style="font-size: 0.36em; line-height: 1.32; text-align: left; margin: 0; padding: 1em; background: #2c3143; color: #e2e8f0; border-radius: 0.25em; white-space: pre-wrap;"><code style="display: block; background: transparent; color: #e2e8f0; padding: 0;">{[
  'class: GalaxyWorkflowDraft',
  'inputs:',
  '  reads:',
  '    type: collection',
  '    collection_type: list:paired',
  'steps:',
  '  align_reads:',
  '    tool_id: TODO_mapper',
  '    tool_version: TODO',
  '    _plan_context: "map paired reads to the reference"',
  '    _plan_in:',
  '      reads: "paired input collection"',
  '      reference: "selected genome"',
  '    in:',
  '      reads: reads',
  '      reference: TODO_reference_port',
  'outputs:',
  '  aligned_bam:',
  '    outputSource: align_reads/TODO_bam_output',
].join('\n')}</code></pre>
</div>

<div class="text-sm opacity-70" style="margin-top: 0.5em; max-width: 33em; margin-left: auto; margin-right: auto;">
  <code>gxwf draft-validate</code> checks what's already concrete against real tool schemas and <strong>skips</strong> what's still deferred — so every intermediate plan is valid at the resolution it has reached.
</div>

</section>


<section>

<h2 style="font-size: 1.26em;">The draft tells you what's next</h2>

<div style="font-size: 0.66em; line-height: 1.26; margin: 0.05em auto 0.7em; max-width: 30em;">
  Because deferral is typed, the tooling reads the plan and picks the next unresolved step — no hunting through YAML for what's unfinished.
</div>

<pre style="font-size: 0.5em; line-height: 1.4; margin: 0 auto; max-width: 28em; text-align: left;"><code style="padding: 0.85em; display: block;">{[
  "$ gxwf draft-next-step wf.gxwf.yml",
  "",
  "→ step 3  filter significant peaks   [deferred]",
  "    _plan_state: keep rows with padj < 0.05",
].join("\n")}</code></pre>

<div class="text-sm opacity-70" style="margin-top: 0.6em;">Resolve it, validate, repeat — the format drives the loop instead of you tracking it.</div>

</section>
